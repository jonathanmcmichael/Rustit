# Easter-Egg Policy

Rustit is serious construction software built by people who are still allowed to enjoy things.

## Priority one: Dungeon Crawler Carl

When a demo project, synthetic fixture, test object, milestone alias, or harmless UI label needs personality, prefer a spoiler-free **Dungeon Crawler Carl** reference. The deterministic first project codename is **Princess Donut**.

The approved reference palette is deliberately recognizable and shallow:

- Princess Donut, Carl, Mongo, and Mordecai;
- The Royal Court;
- crawlers, dungeon floors, safe rooms, tutorials, and achievements; and
- Borant only as a fictional label in synthetic data, never as a real vendor.

Older Space King, Aqua Teen Hunger Force, Sassy the Sasquatch, and Big Lez references remain welcome after the DCC priority slots.

## Guardrails

- Keep references spoiler-free and short. Do not copy dialogue, passages, artwork, logos, or audio.
- Use references only in demos, fixtures, tests, codenames, documentation flavor, and nonessential UI text.
- Do not put fandom terminology in public domain types, IFC mappings, database schemas, vendor contracts, file formats, or required user workflows.
- A fixture's expected result must still be independently verifiable; a funny case name is not evidence.
- Never imply affiliation with or endorsement by Matt Dinniman, the publisher, performers, or rights holders.
- If a reference makes the product less understandable to a newcomer, put the plain construction meaning next to it.

The canon can grow through a narrow pull request. Architectural decisions still require evidence, not charisma—even when Mongo is involved.
