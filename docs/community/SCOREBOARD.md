# Community Evidence Scoreboard

The scoreboard is a recurring maintainer snapshot of useful project evidence. Update it through a pull request at meaningful milestones; it is not a real-time productivity leaderboard.

## Baseline — 2026-08-13

| Evidence | Baseline |
| --- | ---: |
| Completed foundational pull requests | 4 |
| Workspace tests | 28 |
| Rendered semantic object types | 1 (`Wall`) |
| Kernel graduation gates fully demonstrated | 1 of 8 |
| Published starter work packets | 4 |
| Active domain reviewers beyond bootstrap maintainer | 0 |

## What future updates should report

- work packets completed by contribution lane;
- new or strengthened truth fixtures;
- regressions caught before merge;
- deterministic round trips and performance baselines;
- first-time and returning contributors;
- review coverage by domain;
- known blockers and provisional technology risks; and
- a short visual demonstration of the current vertical slice.

## What is deliberately excluded

Prompt count, AI tokens, generated lines of code, commit volume, and leaderboard-style rankings are not measures of project value. Rustit rewards durable evidence and collaborative review.
